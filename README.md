# RedDeerMoultTiming
Data and code for "Moult timing as a measure of condition in a northern hemisphere ungulate".

Data_SummerMoultPredictor.csv - Data for analyses of age, reproductive status, year and parasite load as predictors of summer moult.

Data_WinterMoultPredictor.csv - Data for analyses of age, reproductive status, year and parasite load as predictors of winter moult.

PredictorsOfMoult.R - Accompanying code for running analyses of age, reproductive status, year and parasite load as predictors of summer and winter moult.

-------------

Data_MoultAsPredictor.csv - Data for analyses using moult as a predictor of calf birth weight, calf survival, adult survival and fecundity. 

MoultAspredictor.R - Accompanying code for running analyses using moult as a predictor of calf birth weight, calf survival, adult survival and fecundity. 

-------------

Data_Parturition.csv - Data for analyses of parturition dates.

MultivariatePhenology.R - Accompanying code for analysing covariances among parturition dates, summer moult and winter moult.
